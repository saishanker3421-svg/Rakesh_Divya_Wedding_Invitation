OPEN IN ECLIPSE
---------------
1. Extract this ZIP.
2. In Eclipse: File > New > Project > General > Project.
3. Name it sai-divya-rakesh-wedding.
4. Right-click the project > Import > General > File System.
5. Select the extracted project folder and import all files and folders.
6. Open index.html in your browser (right-click > Open With > Web Browser, if available).

ADD YOUR OWN SONG
-----------------
Copy your MP3 file into:
assets/music/

Rename the file exactly:
wedding-song.mp3

Final expected path:
assets/music/wedding-song.mp3

The HTML already references that path. No code change is needed.
The website intentionally does not autoplay music. A visitor must press the Music button.
Use a song you have permission to use.

EDIT THE LANGUAGES
------------------
Open js/translations.js.
Edit the matching values under "en" and "te".
The top language toggle applies to all elements marked with data-i18n in index.html.

EDIT THE DESIGN
---------------
Open css/style.css.
The main theme colours are at the top under :root.

EDIT BEHAVIOUR
--------------
Open js/script.js.
It handles the language toggle, open-invitation action, music button and countdown.
